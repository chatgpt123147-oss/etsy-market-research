# Etsy Market Research

A personal, read-only research tool for exploring product niches on Etsy.

It uses the official [Etsy Open API v3](https://developers.etsy.com/documentation/) public listing endpoints to look at any niche or product keyword and summarize:

- common tags
- price ranges
- favorites counts

## What it does not do

- It does not edit or create listings.
- It does not read sales, orders, or any private shop data.
- It does not send messages or emails.
- It does not scrape the Etsy website. Only the official API is used.

## Who uses it

Only the author, on their own computer. It is not a public service.
